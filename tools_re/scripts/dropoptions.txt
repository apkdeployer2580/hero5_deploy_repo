#   cargo run -q -p hl5_probe -- --boot --script tools_re/scripts/dropoptions.txt #       --storage out/dropopt --count _ZN9ItemTable13SetItemOptionEP8ItemInfoa
#
# WHY THIS EXISTS. The stranded band-4 rows `lostdrops.rs` reopened are all
# 영웅 with slot 2 reserved (0xFF); a monster's own band-4 arm fills that slot
# from the drop record, the first host walk did not, and the third line read
# `+랜덤옵션`. Reaching that band by killing things is ~0.25% per kill, so this
# drops the rows directly through the guest's own `MapItem::NewDropItem` —
# the call every drop path ends in, with the return address the `MakeSocket`
# net keys on — and reads the item back.
#
# Expected: every `drop` line prints `empty=[]` (none marked `<-- +랜덤옵션`),
# and `--count SetItemOption` = the number of slots the net had to roll:
# 스톰브링거 bare (1) + 사티라스코트 bare (1) + 지크문드 set (1) = 3. The
# drops that carry the record's pair and the 전설 / 에픽 rows add nothing —
# the net declines them, exactly as it declines every shipped drop.
#
# DO NOT ADD THIS TO `ab_905.sh`'s scene list — it exists to move a counter
# and print bytes, not to be compared as pixels.
