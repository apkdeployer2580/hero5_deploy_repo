# Buff timers in real seconds and the buff rebalance (hl5_core::skilltime,
# ANALYSIS.md 71).
#
#   cargo run -q -p hl5_probe -- --boot --storage out/bufftime
#       --script tools_re/scripts/bufftime.txt --skill-time-hz 24 --buff-rebalance
#
# and without either flag for the shipped numbers, or with --skill-time-hz 24
# alone for real seconds without the rebalance. Start from an empty storage:
# the replay makes a new 워리어 in slot 1, the way expkill.txt does. Delete
# out/bufftime-text.txt between runs — `skilltext` appends the guest's own
# skill text to it (EUC-KR).
#
# A new character has no talents, so `learn` writes the rows a 특성 point or a
# skill book would, and `belt` puts them on keys with the guest's own
# HERO::SetHotKeyBelt. A belt slot holds the class's *action* number, which
# `<CLASS>::GetRealSkillIndex` maps to a row through the table at HERO+0x2002 —
# `skillmap` prints it.
#
# What to read off the `buffs` lines, ticks as the guest holds them (the guest
# adds 1 to a duration):
#
#                       shipped     --skill-time-hz 24   + --buff-rebalance
#   돌진 cooldown (ctl)  80          80                   80
#   발악 buff slot       341         817                  1633
#   발악 cooldown        10          24                   24
#   전투태세 stance      341         817                  1633
#   도발 SP spent        300         300                  600
#   도발 cooldown        240         576                  1152
#   도발 무적 slot       21          49                   97
#
# and 900 ticks later the shipped 발악 is gone while the others still run.
# The text (`skilltext`): 발악 "34초" / "34초" / "68초"; 도발 "SP 30 · 24초 ·
# 2초" / same / "SP 60 · 48초 · 4초". With --skill-time-hz the text of what
# is NOT armed in real seconds shows real seconds instead (ANALYSIS.md 71.9):
# 돌진 "8초" -> "3.3초", 고통 "4초 · 22초" -> "1.7초 · 9.2초", 포대 "20초 ·
# 15초" -> "8.3초 · 6.3초", 그림자밟기 "0.5초 단축" -> "5%", 섬광탄 "30초" ->
# "12.5초"; the buffs keep theirs.
#
