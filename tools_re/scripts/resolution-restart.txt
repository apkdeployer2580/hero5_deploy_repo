# 해상도 — the restart prompt a change raises, and both of its answers.
#
#   rm -rf out/res-storage
#   cargo run -q -p hl5_probe -- --boot --storage out/res-storage \
#       --screen-option --screen 2340x1080 --boot-mode skip-network \
#       --count MC_knlExit --script tools_re/scripts/resolution-restart.txt
#
# Navigation is `option.txt`'s, and its warnings apply: the first key after
# the title tap only wakes the highlight, so the centre cell is
# right, right, down.
#
# What this one is for is the popup. `screen::ask_restart` raises the guest's
# own 게임종료 dialog (id 8) with a body of its own, and the guest answers it:
# 예 -> MC_knlExit, 아니오 -> the popup closes and the row keeps its new value.
# So the acceptance is two numbers and two pictures, not byte identity — this
# is a deliberate behaviour change and does NOT belong in `ab_905.sh`.
