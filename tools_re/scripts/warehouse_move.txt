# 공용창고 입출고 — the frames the listing alone does not exercise.
#
#   S=out/wh-storage           # must already hold a save; see warehouse.txt
#   cargo run -q -p hl5_probe -- --boot --free-shop --offline-menus \
#       --storage $S --script tools_re/scripts/warehouse_move.txt
#
# warehouse.txt proves the menu *opens*; this one drives the two things that
# make it a warehouse. It exists to be watched rather than to assert: the
# request payload of every category-4 frame is logged as hex by
# `localserver.rs`, so running this and reading the log is how the deposit and
# withdrawal formats get pinned to observed bytes instead of to a reading of
# the disassembly alone (ANALYSIS.md §25 — the shop's wire format was recovered
# exactly this way, after two guesses that looked right and were not).
#
# The prefix as far as the grid is warehouse.txt's, unchanged.
