# Verify the experience path actually runs: walk into monsters, attack, and
# let one die.
#
#   cargo run -q -p hl5_probe -- --boot --script tools_re/scripts/expkill.txt #       --storage out/xp --new-cash-items --count 0xc06ec
#
# WHY THIS EXISTS. `ingame.txt` enters `Monster::SetDieMotion` 150 times and
# reaches its experience award ZERO times, because that function opens with
#
#     0xc0688  ldr r3, [r0, #0xf0]
#     0xc0694  cmp r3, #0
#     0xc06a0  ble #0xc06ac          ; <= 0: fall through to the award
#     0xc06a4  add sp, #0xc / pop    ; > 0: return at once
#
# and every one of those 150 calls takes the early return. So `ingame.txt`
# cannot verify anything about experience, and the `--count 0xc06ec` it reports
# is 0 for a reason that has nothing to do with the host.
#
# DO NOT ADD THIS TO `ab_905.sh`'s scene list. Like `keep-walking.txt` and the
# joystick pair, this exists to move a counter, not to be compared as pixels.
#
# The attack button is OK, which the guest sees as key -5 (`key select`). The
# touch joystick's centre is about (60, 200) in WIPI coords and it has a
# +-10 px dead zone, so a `move` has to clear that to register a direction.
# The stick is held with `press`/`move` and released with `release`, and the
# hero keeps walking while OK is pressed (that is what `keep_walking` fixed),
# so the two can overlap.
# Online run: new game, skip the opening, land in gameplay, open the menu.
#
#   python tools_re/testserver.py --port 7301
#   cargo run -q -p hl5_probe -- --boot --server 127.0.0.1:7301 #       --script tools_re/scripts/ingame.txt --film out/film
#
# See newgame-online.txt for the tap-then-select rule and the measured menu
# geometry. Two things this script adds:
#
#   * The opening cutscene has a SKIP button at (28, 10) and it works on the
#     first tap -- no confirm, no second select. It drops straight to the
#     loading screen.
#   * One of that loading screen's rotating tips is the answer to "why is the
#     cash shop unreachable": 캐쉬 상점 이용을 위해서는 최소 1회 저장을 해야
#     합니다 -- the shop needs the game saved at least once.
