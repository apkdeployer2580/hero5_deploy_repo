# 창고접속 with no server — the menu must open, and each server-only item must
# say so in the guest's own popup rather than bouncing out with (302).
#
# **This scene needs a save already in the storage directory.** 창고접속 goes
# 창고접속 -> 슬롯선택 first, and with three `empty` slots it stops there and
# never dials at all. So run something that saves into the same directory first:
#
#   S=out/wh-storage
#   rm -rf $S && mkdir -p $S
#   cargo run -q -p hl5_probe -- --boot --storage $S \
#       --script tools_re/scripts/npcmenu.txt          # reaches gameplay, saves
#   cargo run -q -p hl5_probe -- --boot --free-shop --offline-menus \
#       --storage $S --script tools_re/scripts/warehouse.txt --film out/wh-film
#
# There is no shorter way in: nothing on the in-game menu returns to the title
# (`key back` opens the character sheet), so the save has to come from a
# separate run.
#
# What to look for in the log:
#   * `localserver: nickname -> "…"`            the 1/3 answer
#   * `localserver: 2/3 declined — offline`     판매거래소
#   * `localserver: 4/6 declined — offline`     창고관리
#   * `localserver: 8/3 declined — offline`     우편함
#   * **no** `NETWORK::setError`, and no `— no handler` for anything but `0/2`,
#     which wants no answer (ANALYSIS.md 32.7)
