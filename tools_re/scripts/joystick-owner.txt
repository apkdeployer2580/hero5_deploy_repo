# Two fingers on the touch joystick: does the guest still know which one owns it?
#
# The guest gives the stick an owning finger. `StateGame::TouchPressed+0x250`
# (0xE1CCC) writes `gv+0x125 = 1` and `gv+0x124 = <the pressing pointer id>`,
# and `StateGame::TouchReleased+0xdc` (0xE18E8) lets go of the stick only when
# `cmp id, (i8)gv+0x124` matches — the coordinates are not consulted at all.
# ANALYSIS.md 37.5.
#
# So the whole question is whether the host tells the guest which finger moved.
# It used to pass a literal 0 for every one of them, which made that comparison
# always true, and lifting a button let go of the stick.
#
# Run this and its twin, which is the same script with every finger reporting
# id 0 — the way the shell used to behave:
#
#   cargo run -q -p hl5_probe -- --boot --storage out/joy-owner-storage \
#       --script tools_re/scripts/joystick-owner.txt
#   cargo run -q -p hl5_probe -- --boot --storage out/joy-noowner-storage \
#       --script tools_re/scripts/joystick-noowner.txt
#   python tools_re/ab_compare.py out/shot/tf-02-still-held.png \
#       out/shot/tf0-02-still-held.png
#
# The pass condition is the picture. `tf-01` — the stick just grabbed, before
# the second finger arrives — is **byte-identical** between the two runs, and
# `tf-02` — after three taps from that second finger — **differs**: measured,
# 4,027 of 96,000 pixels, the first at (59, 139), which is the joystick itself.
# With the ids wired the ring is still on screen; with every finger claiming
# id 0 it is gone, because the second finger's lift let go of it.
#
# Counters do *not* separate the two runs, and it is worth writing down why,
# because reaching for them first is the obvious move: the stick is grabbed
# twice and released twice either way, so `--count 0xe1ccc` (the grab at
# `TouchPressed+0x250`) and `--count 0xe18f8` (the release block in
# `TouchReleased`) both read 2/2. Only the *timing* differs — in the broken run
# the impostor's first lift releases it and the owner's own release then finds
# nothing left to do. The frame is the evidence; the count is not.
#
# The prologue is `ingame.txt`'s, up to the point where the quest popup is
# dismissed and the touch UI is on screen. See that file for the geometry and
# for the tap-then-select rule.
