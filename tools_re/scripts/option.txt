# 환경설정 — the option list, with the host's four rows (`hl5_core::options`):
# 화면필터 under 화면효과 (display 5), 패드키 under 터치방식 (display 9), 배치변경
# under it (10) and 해상도 last (display 11). The guest's 데이터 관리 is not shown. This script is about the 해상도 row
# (`hl5_core::screen`); 화면필터 / 패드키 have `padmap.txt`, 배치변경
# `hudlayout.txt`.
#
#   cargo run -q -p hl5_probe -- --boot --storage out/opt-storage \
#       --screen-option --screen 2340x1080 --boot-mode skip-network \
#       --script tools_re/scripts/option.txt
#
# The main menu is a 3x3 grid and 환경설정 is the middle cell:
#
#     게임시작   익스퍼트   창고접속
#     업데이트   환경설정   달성과제
#     도움말     게임문의   게임종료
#
# **The first key after the title tap does not move the highlight** (the same
# trap CLAUDE.md records for 창고접속), so reaching the centre is
# right, right, down — not right, down.
#
# The list is twelve rows — eight of the guest's nine plus the host's four —
# and 해상도 is the last. Eleven `down`s from the top land on it (every UP/DOWN
# is answered by `options::key_hook`, which wraps at twelve where the guest's
# own wrap went 8 -> 0).
#
# **Every value change here raises the restart prompt** (`screen::ask_restart`,
# the guest's own two-button 게임종료 dialog with a body of ours), and until it
# is answered it owns the keys and the touches. So each change below is
# followed by `key back`, which the popup treats as 아니오 — it closes and the
# row keeps its new value. `key select` there would take the *first* button,
# 예, and close the game. The prompt has a script of its own:
# `resolution-restart.txt`.
#
# NOT for `ab_905.sh`. It exists to look at one screen, and the 해상도 row is
# a deliberate behaviour change, so byte-identity is not what it is for.
