#   cargo run -q -p hl5_probe -- --boot --avatar --script tools_re/scripts/spirit-avatar.txt

# (`0 0 0=100001 1=110011 4=110024 s=130010`: 마법사 모자, astra 01's body,

# and lets the opening story run instead of skipping it, tapping the dialogue
# on every 45 frames. 400x240 — do NOT add `--screen`.
#
# A scene does not move the hero's own sprite: `Event_PlayerChange(1)` builds
# him anew as an NPC body (`npc_g.dat` record 0) through `Map::NpcPathSet`,
# which never passes `SetLoadImgPath`. That happens here at the dark "voice"
# scene (frame ~3650, after the laboratory dialogue). 렌 is an NPC in scenes

# it, so `npcbody 1` loads her record through `QuestMgr::LoadNpcBody`, the
# fourth caller of the same function.
#

#      every one of these frames is byte-identical except this box, where the
#      teal-haired hero in his equipment stands instead.

#      laboratory's NpcCreate of record 0, the dark scene's PlayerChange(1),

#   3. `npcbody 1` prints `/c/sp/img0/321.mgr / /c/sp/img1/321.mgr` — her
