#
#   cargo run -q -p hl5_probe -- --boot --avatar --script tools_re/scripts/avatar.txt
#
# 400x240 — do NOT add `--screen`, every tap below is in those coordinates.
# The page's origin is x0 = halfW-0x58, y0 = halfH-0x66 = (112, 18); the
# button is the guest's own `*취소` slot at (x0, y0+0xa2), tabs are at
# y0+0x44 every 28 px, rows at y0+0x58 every 18 px (`hl5_core::avatar`).
#
# Evidence:
#   1. avatar-char.png has `*아바타` at the bar's left end, beside `#상세`.
#   2. A tap on it opens the wardrobe (avatar-open.png) — the tap goes through
#      the guest's own `KeyPress('*')`, so `opened 1x` is the guest's hit test
#      and the key hook agreeing.
#   3. 갑옷 -> 가시나무갑옷, 무기 -> the second legendary, 투구 -> 마법사 모자 (the
#      first costume drawn for this project, composed onto the archive's own
#      bare head at boot — `costume: 5 of 5 costume sheet(s) served`): the
#      header's figure changes each time (avatar-armour/-weapon/-hat.png), the
#      summary line says `3 change(s)` and a non-zero `layer(s) dressed`, and
#      `<storage>/hl5_avatar.txt` holds `0 0 0=100001 1=6023 4=26`.
#
