# Hero5 아바타 초안 v1

**실제 인게임용 도트 v3 (2026-10-14):** [실제 착용 갤러리](native/index.html) · [게임용 리소스와 검증 기록](native/README.md) · [v2→v3 비교](native/overview_v2_vs_v3.png). v3 는 리그로 대기·걷기 프레임마다 다른 머리칼·자락 그림, 머리칼과 분리한 눈, 직업별 무기(검·쌍단검·총·창+방패), 아바타 색 이펙트를 더했다. 아래는 최초 콘셉트 단계 기록입니다.

첨부한 11개 스크린샷을 순서 그대로 대응시킨 외형 검토용 초안입니다. 이름은 작업용 가칭입니다.

- `references/`: 제공된 원본 스크린샷 11장
- `drafts/`: 새로 생성한 개별 PNG 11장
- [catalog.json](catalog.json): 번호·이름·파일 대응표
- [prompts.md](prompts.md): 내장 image_gen으로 사용한 프롬프트

## 제작 범위

도트풍 전신 대기 자세의 콘셉트 이미지입니다. 실제 Hero5 픽셀 격자·팔레트·프레임 규격에 맞춘 납품용 시트가 아니며, 런타임에 등록하지 않았습니다. 생성 이미지의 체형과 픽셀 밀도는 개별 편차가 있어 게임용 제작 시 원본 캐릭터 기준으로 통일해야 합니다. 투명 배경으로 생성했습니다.

## 현재 코드 기준 적용 규칙

확인한 근거: `hl5_core/src/avatar.rs`, `hl5_core/src/costume.rs`, `costumes/README.md`.

1. 옷장은 투구(img0), 갑옷(img1), 장갑(img2), 신발(img3), 무기(img4), 방패(img6) 6부위입니다. 이 11종에는 별도 방패 디자인이 없습니다.
2. img5는 직업 이펙트입니다. 망토·날개 전용 슬롯이 아니므로 어깨 장식과 코트는 몸 레이어 및 실제 그리기 순서를 확인해야 합니다.
3. 머리 베이스 img0/000은 7이미지이며 2·5는 자리표시입니다. 몸·팔·다리·무기는 각각 원본 시트의 전체 인덱스와 모션을 따로 조사해야 합니다.
4. 프레임 확장은 양쪽 대칭으로 하여 중심 좌표를 유지하고 원본 이미지 수를 보존해야 합니다.
5. 런타임 색상은 RGB565이며 투명색은 0xF81F입니다. 초안 PNG를 그대로 MGR로 바꾸면 게임용 시트가 되지는 않습니다.
6. 기존 costume catalog의 ID와 시트 번호를 확인한 후 신규 번호를 배정합니다. 이번 문서의 01~11은 검토 번호이며 런타임 ID가 아닙니다.

## 후속 제작 순서

외형 선택/수정 → 실제 베이스 크기에 맞춘 픽셀 정리 → 부위 분리 → 방향/모션별 프레임 제작 → catalog 및 costume 데이터 등록 → 메뉴 미리보기와 필드 이동·공격·장비 교체 검증.
