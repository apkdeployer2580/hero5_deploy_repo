# 게임패드 — 플레이어용 안내

블루투스/USB 게임패드를 연결하면 **연결하는 것만으로 바로 됩니다.** 설정을
켜거나 앱을 다시 시작할 필요가 없고, 게임 중에 연결해도 즉시 잡힙니다.

기술적인 근거와 왜 이런 구조인지는 [`ANALYSIS.md`](../ANALYSIS.md) §52.

## 기본 배치

**스틱이 없는 패드**(십자키 + A/B/X/Y + L1/L2/R1/R2 + SELECT/START)에서도 전투에
쓰는 것 전부와 퀵슬롯 페이지가 버튼에 옵니다.

| 패드 위치 | 흔한 표기 | 하는 일 |
|---|---|---|
| 왼쪽 스틱 / 십자키 | — | **이동** (스틱은 5° 단위, 십자키는 4방향) |
| 면버튼 아래 | Xbox `A` · PS `✕` · Switch `B` | 확인 / 공격 |
| 면버튼 오른쪽 | Xbox `B` · PS `○` · Switch `A` | 취소 / 캐릭터창 |
| 면버튼 왼쪽 | Xbox `X` · PS `□` · Switch `Y` | **퀵슬롯 1** |
| 면버튼 위 | Xbox `Y` · PS `△` · Switch `X` | **퀵슬롯 2** |
| 왼쪽 어깨 | `L1` / `LB` | **퀵슬롯 3** |
| 오른쪽 어깨 | `R1` / `RB` | **퀵슬롯 4** — *메뉴 안에서는 아이템·스킬 설명 켜기/끄기* |
| 왼쪽 트리거 | `L2` / `LT` | **퀵슬롯 5** |
| 오른쪽 트리거 | `R2` / `RT` | 콤보 스킬 |
| 가운데 왼쪽 | `SELECT` / `−` / `SHARE` | **퀵슬롯 페이지 넘기기** |
| 가운데 오른쪽 | `START` / `+` / `OPTIONS` | **대시** |
| 오른쪽 스틱 누르기 | `R3` | 지도 *(스틱 있는 패드만)* |
| 왼쪽 스틱 누르기 | `L3` | 저장 *(스틱 있는 패드만)* |

> **지도·저장이 스틱 누르기인 이유:** 스틱 없는 패드에는 버튼이 열 개뿐이고
> 넣을 동작은 열둘입니다. 그래서 **전투 중에 쓰지 않는 둘**을 스틱 누르기로
> 보냈습니다 — 지도와 저장은 화면 위쪽 `map shop save` 바에 항상 있으니
> 스틱이 없는 패드에서도 **탭 한 번으로 됩니다.** 잃는 기능은 없습니다.

> **버튼 이름이 아니라 "자리"로 적은 이유:** 안드로이드는 면버튼을 위치로
> 보고합니다. 그래서 같은 버튼이 Xbox 패드에는 `A`, 스위치 패드에는 `B`,
> 플레이스테이션 패드에는 `✕` 로 인쇄돼 있습니다. 화면의 배지도 같은 이유로
> 글자가 아니라 **자리 그림**을 그립니다.

## 화면마다 달라지는 둘

버튼 하나가 화면에 따라 다른 일을 하는 자리가 둘 있습니다. 게임 자신이 그렇게
만들어져 있어서, 패드도 그대로 따라갑니다.

### 오른쪽 어깨(`R1`) — 필드에서는 퀵슬롯 4, 메뉴에서는 **설명 보기**

가방·특성·스킬·장비·정령·연계기, 그리고 도감·조합·제련·상점·창고·우편함
에서 `R1` 을 누르면 **아이템/스킬 설명 상자가 켜졌다 꺼집니다.** 게임 자신의
기능이고(화면 구석의 `#` 표시가 그것입니다), 필드로 돌아오면 `R1` 은 다시
퀵슬롯 4 입니다.

`SELECT` 도 같은 `#` 이라 메뉴에서는 똑같이 설명을 켭니다.

> 설명이 안 켜지는 화면이 있습니다 — 목록의 **바깥 칸**(탭 줄, 분류 목록)에
> 커서가 있거나, 도감처럼 **아직 갖고 있지 않은 항목**이면 게임이 스스로
> 거절합니다. 항목을 하나 짚은 뒤에 누르세요.

### 정령 스킬창 — 면버튼이 동서남북

정령 스킬을 쓰면 화면 가운데에 스킬 네 개가 동서남북으로 뜹니다. 그 창이
떠 있는 동안에만 면버튼이 그 네 방향을 맡습니다.

| 패드 위치 | 정령 스킬창에서 |
|---|---|
| 면버튼 위 (`Y`) | **북** |
| 면버튼 아래 (`A`) | **남** |
| 면버튼 왼쪽 (`X`) | **서** |
| 오른쪽 어깨 (`R1`) | **동** |
| 면버튼 오른쪽 (`B`) | 취소 (평소와 같음) |
| 스틱 · 십자키 | 네 방향 전부 |

**누르면 바로 시전됩니다** — 커서를 옮기는 것이 아닙니다. 비어 있는 자리를
누르면 아무 일도 없고 창은 그대로 있습니다.

동(오른쪽)이 면버튼이 아니라 어깨인 이유는 **취소를 `B` 에 남겨 두기
위해서**입니다. 정령 스킬창은 시간을 멈추므로 나갈 길이 반드시 있어야 합니다.

창이 닫히면 면버튼은 즉시 원래대로(확인·퀵슬롯) 돌아옵니다.

## 화면 배지 — 어느 버튼이 어느 슬롯인지

패드가 연결돼 있으면 인게임 화면의 각 컨트롤(퀵슬롯 다섯, 콤보, 페이지, OK)
왼쪽 아래에 작은 동전 모양 표시가 붙습니다. 그 안의 그림이 **패드에서의 자리**를
말합니다:

* **네 점의 다이아몬드** = 면버튼 넷. 밝은 점이 그 버튼입니다.
* **2×2 막대** = 어깨/트리거 넷. 왼/오른쪽 × 위(어깨)/아래(트리거).
* **알약 둘** = 가운데 작은 버튼 둘. 왼쪽이 밝으면 SELECT, 오른쪽이면 START.
* **원 둘** = 스틱 누르기. 채워진 쪽이 그 스틱입니다.
* **십자** = 십자키.

패드를 빼면 사라집니다. 항상 보이게 하거나 아예 끄려면 아래 `hl5_pad_hud.txt`.

## 대시에 대해

대시는 게임 자신의 **더블탭 대시**를 씁니다 — 즉 **주인공이 보고 있는 방향으로**
나갑니다. 서 있을 때도 되고, 달리는 중에 누르면 그 방향으로 나갑니다. 방향을
바꾸면서 대시하려면 스틱/십자키로 방향을 먼저 잡으세요.

## 바꾸고 싶으면 — `hl5_gamepad.txt`

앱의 파일 폴더(`<files>/`)에 `hl5_gamepad.txt` 를 만들면 한 줄에 하나씩
바꿉니다. 형식은 `<안드로이드 키코드>=<토큰>` 입니다.

```
# 줄 맨 앞의 #은 주석입니다 (오른쪽의 #은 퀵슬롯 페이지 키를 뜻합니다)
105=DASH     # 오른쪽 트리거를 대시로 (콤보 자리를 빼앗습니다)
108=7        # START 를 콤보로
109=MAP      # SELECT 를 지도로
97=NONE      # 면버튼 오른쪽을 아무것도 안 하게
```

**쓸 수 있는 토큰**

| 토큰 | 뜻 |
|---|---|
| `UP` `DOWN` `LEFT` `RIGHT` | 방향 (필드에서는 이동, 메뉴에서는 커서) |
| `OK` | 확인 / 공격 |
| `CLR` | 취소 / 캐릭터창 |
| `0`..`9` `#` `*` | 전화기 키 그대로. 퀵슬롯은 `1` `3` `9` `*` `0`, 콤보는 `7`, 페이지는 `#` |
| `PAGE` | 퀵슬롯 페이지 (= `#`) |
| `MAP` `SHOP` `SAVE` | 인게임 바의 지도 / 상점 / 저장 |
| `DASH` | 대시 |
| `NONE` | 그 버튼을 무시 |

**흔한 안드로이드 키코드**: 면버튼 아래 96 / 오른쪽 97 / 왼쪽 99 / 위 100,
어깨 L1 102 · R1 103, 트리거 L2 104 · R2 105, 스틱 누르기 L3 106 · R3 107,
START 108, SELECT 109, 십자키 19·20·21·22.

읽을 수 없는 줄은 **무시하고 넘어갑니다** — 오타 때문에 게임이 안 뜨는 일은
없습니다. 파일은 앱을 켤 때 한 번 읽습니다.

같은 키코드를 두 번 쓰면 **아래 줄이 이깁니다.** `96=NONE` 다음에 `96=OK` 라고
쓰면 그 버튼은 확인입니다.

**배지가 안 붙는 자리가 있습니다** — 위 목록에 없는 키코드(패드 뒷면 패들,
키보드 키 등)에 묶으면 **동작은 하지만** 화면의 배지는 안 따라갑니다. 그 자리를
가리킬 그림이 없기 때문입니다.

## 배지 표시 — `hl5_pad_hud.txt`

| 값 | 뜻 |
|---|---|
| `auto` | 기본값. 패드가 연결돼 있을 때만 표시 |
| `on` | 항상 표시 |
| `off` | 표시하지 않음 (버튼은 그대로 동작합니다) |

## 알려진 것

* **트리거만 아날로그로 보내는 패드도 됩니다** — 축 값을 눌림으로 바꿔서 같은
  표를 지나가므로, `104`/`105` 를 바꾸면 아날로그 트리거에도 적용됩니다.
* **십자키만 있는 기기**(TV 리모컨 등)는 이동이 되지 않습니다. 게임 패드로
  보고되는 기기여야 합니다.
* SELECT/START 가 없는 패드라면 `hl5_gamepad.txt` 로 페이지와 대시를 다른
  버튼에 옮기세요.
* 화면 터치는 그대로 다 됩니다. 패드와 손가락을 섞어 써도 되고, 스틱을 잡은
  채로 화면 버튼을 눌러도 스틱이 풀리지 않습니다.
* **스틱을 놓았는데 계속 걷는다면** 그 패드가 중립에서 흔들리는 폭이 큰
  것입니다. 안드로이드에 자기 흔들림을 알려 주는 패드는 그 값으로 잘라내고,
  안 알려 주는 패드를 위해 호스트가 따로 하한을 둡니다(중립 반경의 약 25%).
  그래도 남으면 십자키를 쓰세요.
